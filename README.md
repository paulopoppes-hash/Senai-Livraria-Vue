# Senai-Livraria-Vue

Livraria — Vue.js

## Descrição

Aplicação web de livraria desenvolvida com Vue.js 3, demonstrando reatividade, Composition API e renderização condicional de listas.

## Tecnologias

- Vue.js 3
- HTML5
- CSS3
- JavaScript

## Conceitos aplicados (Aula 03)

- Reatividade automática (ref)
- Composition API (createApp, setup)
- Renderização de listas (v-for)
- Renderização condicional (v-if)
- Componentização

## Como executar

Abra o arquivo `index.html` em qualquer navegador moderno.
